# Linux hotspot
热点

## 安装
```
paru -S linux-wifi-hotspot
```

## 配置热点
### 打开配置页面
在命令行输入`wihotspot`或查询wifi hotspot应用打开配置页面

![屏幕截图_20260411_214821](https://raw.githubusercontent.com/zhougengxu1990/picture-go/master/屏幕截图_20260411_214821.png)

### 配置
配置`SSID`和`Password`(注：open不要勾选，勾选是无密码)，点击右正角`Create hotspot`即可创建成功

![屏幕截图_20260411_212156](https://raw.githubusercontent.com/zhougengxu1990/picture-go/master/屏幕截图_20260411_212156.png)
